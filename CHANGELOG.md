# 1.0.0 — 2026-11-05

First public release.

- Plugin `aurora-design-system`: skills-only (no tools, no hooks, no network).
- Four skills: `aurora` (core doctrine, version resolution, census), `aurora-pages`
  (archetypes, layout, typography, mobile), `aurora-validate` (auditor + browser
  measurement), `aurora-generative` (openui-lang).
- Three canonical demo pages and screenshots for the catalog entry.
- README in English (catalog) and Spanish.
