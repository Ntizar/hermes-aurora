What each one is

Plugin

aurora-design-system

Four skills that teach the agent to build UI with Aurora: resolve the live version from the repository, compose with documented objects only, and validate the page with the system's own auditor. No tools, no hooks, no network calls of its own.

hermes plugins install aurora-design-system

Skill

acceptance-criteria

Write 3–7 falsifiable criteria before starting, each with the command that checks it. When the work ends, check runs them and close refuses while anything is red. «Done» becomes evidence.

The four skills

aurora

Doctrine: step 0 version resolution, pinned links, the 12 hard rules and a need → object table.

aurora-pages

Shape: archetypes, desktop canvas, mobile stacking, typographic scale, surface budget.

aurora-validate

The judge: zero failures from the auditor plus real measurement in a browser before delivery.

aurora-generative

When the model composes at runtime: openui-lang, spec, vanilla runtime and static baking.

How a page gets built

  1. Resolve the version. A tag or the GitHub API, every single time. A version written from memory is wrong the moment a release lands.
  2. Read the generated docs. LLM.md and components.json: about 20 KB instead of 340 KB of CSS in the context.
  3. Compose with the census. Real markup copied from the design system. If a class is not in the census it does not exist, and the skill says so before the model invents one.
  4. Measure, don't admire. The auditor must report zero failures, and the browser must agree: no horizontal overflow at 320/360/390, computed styles present, the primary action above the fold.

This page is the proof. It is built with Aurora from the same census the skills describe, and it passes the same auditor with zero failures and zero warnings.

Install

Plugin

hermes plugins install aurora-design-system --enable

Requires Hermes Agent 0.21 or newer. Verify with hermes plugins validate and hermes plugins doctor.

Skill

hermes skills install https://raw.githubusercontent.com/Ntizar/hermes-skill-acceptance-criteria/main/SKILL.md

Then, before a non-trivial task: harness.py new ... --criterion "text :: command".
